# Problem 355: Maximal Coprime Subset

Define $\\mathrm{Co}(n)$ to be the maximal possible sum of a set of mutually co-prime elements from $\\{1,2,\\dots,n\\}$.  
For example $\\mathrm{Co}(10)$ is $30$ and hits that maximum on the subset $\\{1,5,7,8,9\\}$.

You are given that $\\mathrm{Co}(30) = 193$ and $\\mathrm{Co}(100) = 1356$.

Find $\\mathrm{Co}(200000)$.
