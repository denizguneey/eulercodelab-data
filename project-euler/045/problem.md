# Problem 045: Triangular, Pentagonal, and Hexagonal

Triangle, pentagonal, and hexagonal numbers are generated by the following formulae:

<table><tbody><tr><td>Triangle</td><td>&nbsp;</td><td>$T_n=n(n+1)/2$</td><td>&nbsp;</td><td>$1, 3, 6, 10, 15, \dots$</td></tr><tr><td>Pentagonal</td><td>&nbsp;</td><td>$P_n=n(3n - 1)/2$</td><td>&nbsp;</td><td>$1, 5, 12, 22, 35, \dots$</td></tr><tr><td>Hexagonal</td><td>&nbsp;</td><td>$H_n=n(2n - 1)$</td><td>&nbsp;</td><td>$1, 6, 15, 28, 45, \dots$</td></tr></tbody></table>

It can be verified that $T\_{285} = P\_{165} = H\_{143} = 40755$.

Find the next triangle number that is also pentagonal and hexagonal.
